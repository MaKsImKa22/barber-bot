# Telegram booking bot + barbershop website with local SEO

> Learning/demo project. The barbershop is made up, the address and phone are placeholders.

- Bot: [@barrrber_bot](https://t.me/barrrber_bot)
- Website: [maksimka22.github.io/barber-bot](https://maksimka22.github.io/barber-bot/) (code in `docs/`)

## The bot
Clients book a haircut without calling. It works for any service business (salon, nails, car service).

- Pick a service, a day and a free time slot with buttons
- Busy and past slots are hidden, double booking is impossible
- Phone number with one button or typed by hand (format is checked)
- "My bookings" with cancellation
- The owner gets a message about every new or cancelled booking
- Owner commands: `/today`, `/week`

Run it:
1. Create a bot in [@BotFather](https://t.me/BotFather) and copy the token.
2. Copy `.env.example` to `.env` and paste `BOT_TOKEN`.
3. Run `run.bat`, send `/myid` to the bot, put your ID into `ADMIN_ID` in `.env`, restart.

Business settings (name, services, prices, working hours) are in `config.py`.

Test: `python tests/smoke_test.py` runs the whole booking flow against a fake Telegram API (no token, no network).

## The website and local SEO
- Google PageSpeed Insights (mobile): SEO 100, Accessibility 100, Best Practices 100, Performance 92.
- Google Rich Results Test: 3 valid items (Local business, Breadcrumbs, Organization), no errors.
- A separate page for each service with its own text, price, duration and FAQ.
- Same name, address and phone (NAP) on every page and in the markup.
- Schema.org: `HairSalon` (address, hours, prices, booking through Telegram as `ReserveAction`), `Service`, `BreadcrumbList`, `FAQPage`.
- Breadcrumbs, canonical, Open Graph image, `sitemap.xml`.

All pages are generated by `tools/build_site.py` from one data set, so prices and NAP never go out of sync.
